# Data Structures & Algorithms (DSA) in Java ☕

Welcome to my DSA repository! This project serves as a centralized hub for my implementations of core data structures, classic algorithmic paradigms, and solutions to competitive programming challenges. 

## 🛠️ What's Inside?
- **Data Structures:** Arrays, Linked Lists, Stacks, Queues, Trees, Graphs, and Hash Maps.
- **Algorithms:** Searching, Sorting, Two-Pointers, Sliding Window, Recursion, and Dynamic Programming.
- **Problem Solving:** Categorised solutions from LeetCode, InterviewBit, and HackerRank.
